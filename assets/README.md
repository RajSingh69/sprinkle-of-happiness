# Assets

Future artwork should be placed under `assets/images/` using these groups:

- `dreamland/` for environmental scenes, clouds, moon, sun, phoenix and global dreamland motifs.
- `people/` for community, hands, reflective figures and human connection artwork.
- `objects/` for coffee, tea, paper, envelope, camera, pen and small floating objects.
- `founder/` for Kaan Singh portrait and personal archive imagery.
- `experiences/` for Workshops, Circles, Walks and individual experience artwork.

Prefer compressed WebP for raster images, SVG for intentional vector systems, and transparent PNG/WebP when an asset needs to float over a section. Use meaningful `alt` text for content-bearing images and `aria-hidden="true"` for decorative artwork.

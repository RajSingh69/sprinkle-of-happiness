# Asset Manifest: Sprinkle of Happiness Phase 6B

This manifest describes bespoke artwork still to be created and how each asset should integrate into the current frontend. Do not use random stock images, external URLs, hotlinked media or generated placeholder artwork as final assets. Prefer WebP for environmental raster artwork, transparent WebP/PNG for floating objects, and SVG only where intentional vector/line work is required.

Recommended future asset home: `assets/artwork/`. Existing filenames below may keep their current paths if preferred, but new artwork should use one consistent asset directory before final integration.
